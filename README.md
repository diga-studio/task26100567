# task26100567

`forkdb`：演示数据分叉库（纯进程内存，单线程顺序调用）。

## 设计

- 每个环境的内容存储在不可变的持久化 HAMT（Hash Array Mapped Trie）中，
  修改通过路径复制生成新根，旧根全量共享。
- `Clone` 为 O(1)：只复制两个指针（当前根 + 整条链共享的种子根），
  历史环境零拷贝保留，万代分叉的存活堆内存仅几十 MiB。
- `Reset` 把当前根指回种子根，即恢复整条链最初创建时的种子集。
- 所有入口（种子、批量定制）逐字节拷入，所有读取逐字节拷出，
  调用方持有的字节数组与环境完全隔离。

## API

```go
env := forkdb.NewEnvironment(seed)      // 从种子集创建（拷入）
data, ok := env.Read(id)                // 按标识读取（拷出）
env.Apply([]forkdb.Change{              // 批量定制：新增/整条替换/删除
    {ID: "a", Data: payload},
    {ID: "b", Delete: true},
})
child := env.Clone()                    // 克隆当前完整逻辑副本
env.Reset()                             // 恢复为整条链最初的种子集
```

## 运行验收

```sh
go test -v ./...
```

- `fork_test.go`：多代分叉删除不复活、重置回最初种子且不影响旁支、
  字节数组隔离，以及与“每环境独立完整副本”参考模型的随机比对。
- `scale_test.go`：5000 条 × 2048 字节种子、10000 代克隆+定制（替换/新增/删除）、
  全部历史保留，输出总耗时、GC 后存活堆内存、最深代 20 万次读取耗时
  （限值：10 秒 / 192 MiB / 5 秒）。
