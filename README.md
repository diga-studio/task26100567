# forkdb — 演示数据分叉库

纯进程内存的 Go 库，支持从种子集创建演示环境、批量定制、O(1) 克隆分叉、
重置回最初种子。面向单线程顺序调用，无并发开销。

## 设计

- 每个环境的内容是一棵**不可变 HAMT**（Hash Array Mapped Trie，32 路位图节点）
  的根指针；修改操作路径复制，旧版本结构完全共享。
- 克隆 = 复制根指针，O(1)；此后双方各自路径复制，互不影响。
- 每个环境同时持有分叉链最初的种子根，重置 = 把当前根指回种子根。
- 删除即从该环境的树中移除标识，天然覆盖祖先中的同标识记录，不会复活。
- 写入时复制调用方输入字节，读取时返回独立副本，双向隔离。

## API

```go
env := forkdb.New(seed)              // seed: map[string][]byte，内容被复制
data, ok := env.Get(id)              // 返回独立副本
env.Apply([]forkdb.Mutation{         // 批量定制：新增 / 整条替换 / 删除
    {ID: "a", Data: []byte(`{...}`)},
    {ID: "b", Delete: true},
})
child := env.Clone()                 // 完整逻辑副本，O(1)
env.Reset()                          // 恢复为分叉链最初的种子集
```

## 测试

```sh
go test -v .
```

- `forkdb_test.go`：随机多代分叉与独立全量副本参考模型逐字节对比；
  删除不复活、重置回最初种子且不影响旁支、字节数组防串改、克隆隔离。
- `scale_test.go`：5000×2048 种子、10000 代克隆+定制（反复替换热点标识 +
  持续新增标识）、全部历史环境保留；断言总耗时 ≤ 10s、GC 后存活堆
  ≤ 192 MiB、最深代 20 万次混合读取 ≤ 5s，并输出实测数据。

本机实测（Apple Silicon）：构建 31ms，存活堆 42.5 MiB，20 万读 65ms。
